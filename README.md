# 朝闻 · 综合新闻

汇集国内外一百余家媒体、通讯社与机构公开发布的新闻，每条注明来源与发布时间，外文报道附中文译文，多家来源报道同一事件时自动归并。

在线阅读：<https://mingchuxue.github.io/zhaowen/>

## 功能

- **要闻首页**：按热度挑出头条与各栏目重点，附今日热词与热度榜
- **多源归并**：同一事件的多家报道合并为一条，标明“几家来源报道”，可展开对照
- **多重筛选**：分类、地区、话题、来源类型、语言、具体来源可任意组合，并可按时间或日期筛选
- **排序**：热度、最新、报道数、来源
- **搜索**：多个词同时包含，`-词` 排除，`来源:名称` 限定来源，结果高亮
- **外文译文**：可切换译文、原文或中英对照，单条新闻也能单独切换
- **时间轴**：按日、按小时浏览当天新闻，附每小时报道量分布
- **个人功能**：收藏、稍后读、浏览记录、已读标记、关注关键词与话题、屏蔽来源与关键词、数据导出导入
- **今日简报**：一键生成各栏目要闻摘要，可复制、朗读或打印
- **阅读设置**：深浅色、四档字号、列表密度、配图开关
- **其他**：链接保留筛选状态便于分享、快捷键、无限滚动、手机适配、可安装到桌面并离线打开

## 数据来源

来源清单见 [`tools/sources.py`](tools/sources.py)，包括新华网、人民网、央视网、中国新闻网、澎湃新闻、财新网、第一财经、界面新闻、36氪、虎嗅等国内媒体，以及路透社、美联社、彭博社、BBC、纽约时报、卫报、半岛电视台等境外媒体与机构，另有部分媒体与机构的官方推特账号。部分来源没有公开订阅源，经由 Google 新闻检索获取。

站内只保存各来源公开的标题与摘要，正文请前往原网站阅读，版权归原作者所有。

## 更新方式

GitHub Actions 每两小时运行一次 [`tools/fetch_news.py`](tools/fetch_news.py)：抓取各来源、翻译外文标题与摘要、打标签、归并相同事件、统计热词，然后发布到 GitHub Pages。站点保留最近 7 天的新闻，按天分文件存放于 `data/day/`。

本地运行：

```bash
python -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/fetch_news.py
python -m http.server 8000
```
